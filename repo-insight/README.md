# 🔎 RepoInsight

أداة تحلل المستودعات العامة لأي حساب GitHub: إحصائيات، رسوم بيانية، فحص جودة لكل مستودع، وتقرير قابل للتنزيل.

## المميزات
- عدد المستودعات العامة، Stars، Forks، واللغات المستخدمة.
- أكثر المشاريع Stars، وتوزيع المشاريع حسب اللغة (Recharts).
- المشاريع المتوقفة (لم تُحدَّث منذ أكثر من سنة).
- فحص كل مستودع: README، وصف واضح، LICENSE، ملفات اختبار، Topics، النشاط.
- درجة اكتمال من 100 لكل مستودع (الـ Forks لا تُقيَّم).
- تنزيل التقرير بصيغة Markdown أو CSV أو JSON.

## التشغيل
المتطلبات: Node.js 18 أو أحدث.

```bash
npm run install:all
cp .env.example .env      # اختياري: ضع GITHUB_TOKEN
npm run dev               # الواجهة http://localhost:5173  والخادم :4000
```

للإنتاج: `npm run build && npm start` ثم افتح http://localhost:4000

> بدون توكن حد GitHub هو 60 طلبًا في الساعة، وكل مستودع يُفحص يستهلك طلبًا واحدًا. مع `GITHUB_TOKEN` (بدون أي صلاحيات) يصبح الحد 5000.
> لتمرير التوكن: `GITHUB_TOKEN=xxx npm run dev`

## معايير الدرجة (من 100)
| المعيار | النقاط |
|---|---|
| README في الجذر | 25 |
| ملفات اختبار | 20 |
| وصف واضح (20 حرفًا فأكثر؛ نصف النقاط للوصف الأقصر) | 15 |
| LICENSE | 15 |
| نشاط خلال 180 يومًا (نصف النقاط حتى سنة) | 15 |
| Topics | 10 |

يمكن تعديل الأوزان من `server/analyzer.js` (الثابت `WEIGHTS`).

## الهيكل
```
server/   Express + GitHub REST API (analyzer.js فيه منطق التقييم)
client/   React + Vite + Recharts (واجهة عربية RTL)
```
